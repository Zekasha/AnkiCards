# мой основной репозиторий для обучения<br>
Некоторая часть из колод карточек анки сформированы с помощью ИИ на основе проведённых потоковых лекций <br>
Все колоды в формате apkg <br>
Пытаюсь своевременно обновлять карточки и добавлять новые <br>
## Хорошие каналы, которые я могу порекомендовать: <br>
### Математика: <br>
1. 3blue1brown - https://www.youtube.com/@3blue1brown, это самая база понимания математики, один из лучших каналов, есть дубляж на русский <br>
2. The Math Sorcerer - https://www.youtube.com/@TheMathSorcerer, отличный канал на английском про математику, есть разборы и практических, и теоретических задач <br>
3. Numberphile - https://www.youtube.com/@numberphile, интересный канал про математику и всякие математические задачки, где-то на ютубе есть дубляж на английский <br>
### Информатика: <br>
1. Fireship - https://www.youtube.com/@Fireship, короткие видео на английском, которые позволяют быстро войти в тему, частично обкашливаются новости информационного мира <br>
2. Honey Montana - https://www.youtube.com/@hhoneymontana, интересный русскоязычный автор из околопрограммирования, в целом у него достаточно интересные видео, но глубокого посыла они не несут <br>
3. The Coding Sloth - https://www.youtube.com/@TheCodingSloth, англоязычный автор, делает хороший интересный контент по программированию и информационной сфере <br>
4. IBM Technology - https://www.youtube.com/@IBMTechnology, Да, да, да, знаю, что не каждый день вам советуют посмотреть видео от IBM, но тем не менее у них полно хорошего обучающего контента по широким темам <br>
5. freecodecamp - https://www.youtube.com/@freecodecamp, Тоже один из столпов изучения программирования - вебдев, пайтон, миллионы хороших курсов по всевозможным темам, но на английском, как по мне, стоит изучить английский только для этого <br>
6. NetworkChuck - https://www.youtube.com/@NetworkChuck, отличный канал для изучения того, как работают сети, частично хакинг и к нему прилегающие, короче стоит внимания <br>
